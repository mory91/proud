# Verification

Run:

```sh
nvim --headless -u tests/minimal_init.lua -l tests/run_unit.lua
nvim --headless -u tests/minimal_init.lua -l tests/run_e2e.lua
nvim --headless -u tests/minimal_init.lua -l bench/run.lua
```

No browser implementation may merge without the feature-local unit spec, E2E spec, and benchmark passing. Fixture construction is outside the timed region and the benchmark checks a stable result checksum to prevent dead-code optimizations.

GitHub `createdAt` and REST `created_at` values are converted at normalization time using timezone-safe ISO 8601 parsing. Deterministic unit and E2E cases require `24m`, `1h`, and `1d`; the real-terminal suite renders the same raw timestamp shapes in actual Neovim windows. Preformatted compact ages remain stable. The relative-time workload formats 2,000 timestamps under its own timing and memory SLA.

The real-terminal contract opens an actual Neovim process and checks two native rounded floating windows without native titles, separate list/preview buffers, an unobstructed rounded top edge, and an in-window two-row top section containing the header and a full-width grey separator. The editable `PR > ...` filter prompt and right-aligned `filtered/total` count occupy the first interior row; a muted grey `Preview` header occupies the corresponding row in the preview pane. The second interior row is the separator. The preview is focusable and starts a visible purple cursor on the first content row after those protected rows; real terminal key input moves that cursor through the text and the configured return action restores list focus. The contract also checks a configurable gap between the panes, configurable top/bottom margins that stay clear of Neovim chrome, adjacent PR title/subtitle rows in `name · age · +additions-deletions · thread count · review state` format, straight rows and visible counts at `80x24`, `100x30`, `120x40`, and `160x45`, semantic colors for status, PR numbers, titles, threads, review state, additions/deletions, preview headings, separators, and hidden key hints via `tests/terminal/run.sh`. The responsive contract invokes `surface.resize()` inside actual Neovim windows, changes every floating component's width, and rechecks the complete layout invariants without reopening the scene.

Selection scrolling treats the in-window header and separator as protected rows. Moving up or down preserves the current viewport whenever the complete two-row PR item already fits below that overlay, and scrolls by the minimum amount otherwise. Both headless E2E and the real-terminal contract cover the upper edge explicitly so cursor state cannot advance to a PR hidden behind the top section.

Raw GitHub GraphQL search payloads are normalized and rendered in both feature E2E tests and `tests/terminal/thread_counts_test.exp`. The regression covers `reviewThreads.totalCount` values `3`, `1`, and `0`, and requires the actual terminal to show `3 threads`, `1 thread`, and `no threads`. This prevents fixture-only thread fields from hiding missing API metadata.

Preview metadata is also source-backed. Unit tests feed GraphQL `labels.nodes`, `reviewRequests.nodes`, `latestReviews.nodes`, and `body` values with unique API names and reject leaked fixture reviewers or generated Summary text. Pagination tests divide the live list height by each complete two-row item, append GraphQL cursor pages without duplicates, keep two additional pages prefetched after selection movement, and keep unloaded descriptions in an explicit loading state. The preview retains every line of the fetched first PR message and exposes configurable half-page description scrolling without moving PR selection. Held cursor movement is verified to cancel intermediate description work and fetch only the settled selection after the debounce window. The source selector is verified in unit, headless E2E, and real-terminal tests: it starts on `All open`, exposes all five source labels, gives the active source extra horizontal padding in a one-row borderless solid button, uses `ProudAccent` for the complete purple active fill and `ProudMuted` text on the shared normal background for inactive fills, remains straight and outside the rounded panes, preserves the one-row solid-button style during resize, and reloads the matching query on configurable next/previous keymaps. Rapid source movement coalesces intermediate states into one request for the settled source. Closing a browser disposes both debounce timers and rejects later callbacks. Real-terminal tests open the actual browser surface in Neovim, verify viewport-sized first-page loading, fetch only the preselected description, move with real `j` input, load exactly two sequential cursor pages, bound page and description request counts, and exercise rapid `<Tab>` plus `<S-Tab>` source changes. The metadata terminal contract additionally verifies API reviewer decisions, requested reviewer, labels, complete description, conversation, and description scrolling through real key input.
The lifecycle E2E repeatedly opens and closes this screen through real terminal input, verifies retained heap growth/trend within `64 KiB`, and rejects retained buffers or windows.
