Add retry backoff to robot task runner #482

── Description ─────────────────────────────────────────────────────────────────────────
## Summary
Tasks that hit a transient error (timeouts, 429s, proxy resets) used to retry
3 times with a flat 1s wait, which hammers sites that are rate limiting us.
This adds exponential backoff with jitter and reads limits from runner config.

## Testing
- [x] Unit tests for backoff timing and non-retryable errors
- [x] Ran 200 tasks against a robot with a flaky origin URL
- [ ] e2e in robot studio
